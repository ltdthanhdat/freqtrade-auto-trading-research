## Constraint proof

- cadence target `1 -> 1.5/day` on this window is equivalent to `88 -> 132` trades.
- current baseline only has `89` trades.
- therefore any approach that only `filters out` existing trades can only fall within:
  - `89` trades
  - or `88` trades
- baseline has `56` wins:
  - with `89` trades, need at least `63` wins to exceed `70%`
  - with `88` trades, need at least `62` wins to exceed `70%`
- filtering existing trades alone cannot increase wins from `56` to `62/63`.
- exhaustive check at the level of:
  - `pair`
  - `signal_kind x side`
  - `pair x side x signal`
  - none found a subset that meets the target.

## Conclusion

- light pruning / filtering can raise win rate to the `66% -> 70%` range
- but either cadence fails, or it still does not reach `>70%`
- to achieve the new objective, the thesis must change:
  - create additional high-quality trades
  - or replace losers with a different entry logic
